# Vamsi Krishnam Raju - Portfolio

Static site (HTML + CSS + JS). No build step.

## Run
Open index.html in a browser, or run: python3 -m http.server 8000

## Structure
- index.html      content (experience, projects, communities, contact)
- css/style.css   design tokens at the top (:root); versions via [data-v="1|2|3"]
- js/main.js      version switcher, popups, scroll reveal
